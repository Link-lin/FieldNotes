# Bundled geographic data

Generated by `npm run data:build` on 2026-09-27.

- `places.json`: 7342 populated places from [Natural Earth](https://www.naturalearthdata.com/) v5.1.2 (ne_10m_populated_places, with each place's IANA time zone) and 241 country centroids from Natural Earth 50m admin-0 via the `world-atlas` package. Public domain.
- `airports.json`: 4568 IATA codes (large and medium airports) from [OurAirports](https://ourairports.com/data/) `airports.csv`. Public domain.
- The globe outline uses `world-atlas` land-110m (Natural Earth, public domain) directly from node_modules.

The app never calls a geocoder or map service; these files are the only place data.
