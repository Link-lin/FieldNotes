# Bundled geographic data

Generated by `npm run data:build` on 2026-09-27.

- `places.json`: 7342 populated places from [Natural Earth](https://www.naturalearthdata.com/) v5.1.2 (ne_10m_populated_places, with each place's IANA time zone) and 241 country centroids from Natural Earth 50m admin-0 via the `world-atlas` package. Public domain.
- `map-cities.json`: 5527 city names and points with Natural Earth scale rank 0–7, drawn on the day map when there is room. Derived from `places.json`.
- `airports.json`: 4568 IATA codes (large and medium airports) from [OurAirports](https://ourairports.com/data/) `airports.csv`. Public domain.
- The globe outline uses `world-atlas` land-110m; the day map uses `world-atlas` land-10m coastlines and countries-10m borders (Natural Earth, public domain), directly from node_modules.

The outline day map and globe never call a geocoder or map service. An opened event panel or selected day road view can separately load a Google Maps embed when its API key is configured.
